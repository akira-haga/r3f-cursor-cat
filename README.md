# R3F Cursor Cat

A web application featuring a 3D cat model that follows your mouse cursor, built using React Three Fiber (R3F) and Three.js.

## Demo

- [View Demo](https://r3f-cursor-cat.vercel.app/)

## Getting Started

### Prerequisites

- Node.js

### Installation

1. Install dependencies
```
npm install
```

2. Start the development server
```
npm run dev
```

3. Open ```http://localhost:5173``` in your browser.
